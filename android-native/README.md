# Native Android foundation — engineering preview only
This is a separate native Activity using Android widgets and Java, with no browser, WebView, network permission, shop credentials or access to any existing shop database. It provides a single-item offline quote and cash change calculator with integer centavos plus an app-private preview service/material SQLite catalog, with revision-checked edits, archive/restore and atomic revision history. It does not issue a receipt, create a sale or synchronize. The preview app ID is intentionally distinct from any eventual production app.

Build: JDK 17, Gradle 8.9, Android SDK platform 35 and build tools 34.0.0. Run `gradle -p android-native --no-daemon :app:assembleDebug :app:lintDebug`. The CI gate compiles and executes QuoteMath (13 checks) and CatalogEntry (12 checks), builds the debug and instrumentation APKs, lints, installs both on a disposable Android 14 emulator, and requires native quote and SQLite acceptance markers plus terminal result code. AGP 8.7 compatibility: https://developer.android.com/build/releases/agp-8-7-0-release-notes. Debug signatures are for engineering UAT only. No production signing keys.

Verified: native build, lint, quote and catalog SQLite smoke passed at fd8fee6 in CI 45766719266. Integration against develop must pass independently. Remaining: catalog management screen, orientation/layout/IME acceptance, catalog/service pricing parity (including tiers/materials), authentication, local SQLite migrations and atomic audited checkout, durable replay/stock/receivables, production, reports, receipt printing, secure synchronization and backups, native managed-device kiosk behavior with owner authorization, real device testing. Android scroll fallback is intentional for small or accessibility-scaled screens; no claim of no-scroll acceptance yet. Do not attach a live shop database or use this preview to record payments.
